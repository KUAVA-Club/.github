# KUAVA.CLUB — Reach New Frontiers.

## What is this?

Koç University Aerial Vehicles Association (KUAVA) is a student-led engineering team dedicated to designing, building, and flying innovative drones. Our mission is to push the boundaries of aerial technology, foster interdisciplinary collaboration, and compete at the highest levels nationally and internationally. Learn more at [kuava.club](https://kuava.club).

This org is home to our codebases, tooling, research, and technical documentation related to all things aviation.

---

## Getting Started

If you're a team member or contributor, here's how to get oriented:

1. **Browse the repositories** — each repo has its own README with project-specific setup instructions.
2. **Request access** — reach out via [kuava.club](https://kuava.club) or contact an org admin to be added as a member.
3. **Follow our conventions** — consistent branching, commit messages, and PR reviews keep things running smoothly across projects.

---

## Contributing

We welcome contributions from team members and invited collaborators.

- Open an issue before starting significant work
- Keep PRs focused and well-documented
- All code should be reviewed before merging to `main`
